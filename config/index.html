YukkiMusic Configuration

Environment Setup

Here’s an Example Sample.env

API_ID =
API_HASH =
BOT_TOKEN =
MONGO_DB_URI =
LOG_GROUP_ID =
OWNER_ID =
STRING_SESSIONS =
  • Copy the example.env file to .env
    cp sample.env .env

  • Fill in the necessary variables in your .env :

    • API_ID: The API ID obtained from Telegram.

    • API_HASH: The API hash obtained from Telegram.

    • BOT_TOKEN: The bot token you get from BotFather.

    • MONGO_DB_URI: The MongoDB connection string for your database.

    • LOG_GROUP_ID: The ID of the group to which logs should be sent (set to 0 if no logs are needed).

    • OWNER_ID: The ID of the bot owner.

    • STRING_SESSIONS: Your session string (usually generated via a method like Pyrogram) or You can generate from Telegram Tools And make sure you environment is Production Don’t use Test.
